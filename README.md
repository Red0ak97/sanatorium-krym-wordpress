# Sanatorium Krym — WordPress portfolio

Портфолио-проект сайта санатория «Крым»: собственная WordPress-тема `krym-sea` и плагин галерей `krym-room-photos`. Стек: PHP, WordPress API, HTML, CSS и JavaScript без frontend-фреймворков.

Это адаптированная демонстрационная копия исходного кода, а не резервная копия рабочего сайта. Фотографии заказчика, герб, контакты, база данных и настройки сервера не включены. Изображения заменены нейтральными SVG-заглушками. Ссылки бронирования ведут на локальную демонстрационную страницу контактов; загрузка Google Fonts отключена.

## Реализовано в коде

- Адаптивные страницы, мобильное меню и шаблон номерного фонда.
- Слайдер территории с паузой, остановкой при фокусе и учётом `prefers-reduced-motion`.
- Настройки отображения: размер текста, светлая/тёмная схема, скрытие изображений и сохранение настроек в браузере.
- Редактируемое объявление через WordPress: проверка прав, nonce, очистка текста и экранирование при выводе.
- Галереи шести категорий номеров: модальное окно, стрелки клавиатуры и возврат фокуса.

Наличие этих возможностей не означает подтверждённое соответствие стандартам доступности: полноценная проверка в браузере ещё требуется.

## Локальная установка

1. Подготовьте отдельную установку WordPress. Для воспроизведения используйте PHP 8.2 с `mbstring` и WordPress 6.3 или новее (код темы использует параметр стратегии загрузки скриптов). Матрица совместимости версий не проверена.
2. Скопируйте `themes/krym-sea` в `wp-content/themes/`, а `plugins/krym-room-photos` — в `wp-content/plugins/`.
3. Активируйте тему **Krym Sea** и плагин **Krym — фотографии номеров**.
4. Создайте страницу «Главная» и выберите её статической главной в настройках чтения.
5. Создайте страницы со слагами `o-sanatorii`, `lechenie`, `nomera`, `ceny`, `putevki-2`, `uslugi`, `informaciya`, `kontakty`. Меню в этой версии прописано в `header.php`; зарегистрированная область меню пока не используется для вывода.
6. У страницы `nomera` создайте дочерние опубликованные страницы с названиями **ПК 1.1**, **ПК 1.2**, **ПК 2.2**, **СТ 1.2**, **ЧУ 1.1**, **Люкс 2.2**. Плагин определяет категорию по заголовку. Карточки формируются из дочерних страниц, порядок задаётся полем «Порядок».
7. Добавьте собственный демонстрационный текст. В разделе «Объявление» можно включить информационную строку.

Без базы данных страницы и их содержимое автоматически не создаются. Файл `index.php` оставлен исходным минимальным шаблоном; блог и архивы записей не реализованы полноценно.

## Изображения

Тема использует `assets/img/placeholder.svg`. Галерея плагина показывает заглушку, когда приватные фотографии отсутствуют, поэтому скачанная копия не обращается к отсутствующим фотографиям.

При локальном использовании собственных разрешённых изображений плагин ожидает `assets/images/<category>/cover.webp` и фотографии `01.webp`, `02.webp`, …:

| Категория | Папка | Максимум фотографий |
|---|---|---:|
| ПК 1.1 | pk1-1 | 4 |
| ПК 1.2 | pk1-2 | 4 |
| ПК 2.2 | pk2-2 | 5 |
| СТ 1.2 | st1-2 | 3 |
| ЧУ 1.1 | chu1-1 | 6 |
| Люкс 2.2 | luxe2-2 | 9 |

Плагин пропускает отсутствующие файлы. Локальные фотографии исключены через `.gitignore`; не добавляйте их принудительно.

## Проверка и публикация

Подробности источников, изменений и границ проверки — в [docs/REVIEW.md](docs/REVIEW.md). Старый каталог `.git` не перенесён: публичная история должна начинаться с очищенной копии. `.gitignore` не удаляет уже отслеживаемые файлы и не заменяет просмотр состава коммита.

Перед использованием на реальном сайте проверьте установку в WordPress, все страницы меню, галерею, мобильное меню, клавиатурную навигацию и сохранение объявления под разными ролями.
